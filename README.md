# Timeless Treasures

Timeless Treasures is a handmade jewelry e-commerce website designed to showcase and sell handcrafted jewelry products.

## Project Overview

The website provides customers with a simple and elegant shopping experience where they can:

- Browse jewelry products
- Explore different product categories
- Search for products
- Add products to the cart
- Manage their wishlist
- View product details
- Customize selected products
- Track orders
- Contact the store
- Learn more about the brand

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Fonts
- Responsive Web Design
